# 段階ごとの確認

全段階で `npm install` → `npm run dev` を実行し、表示された `/flamenco-palmas-box/` を開きます。
Git の各コミットは単独でビルド・起動できます。

## 1. 円形表示

- Soleá は12点、Tangos は4点、Sevillanas は3点。Bulerías の先頭は12。
- Play で点が順番に光り、針が1コンパスで一周する。
- 再生中に「従来の表示」「輪っか表示」を切り替えても再生が続く。
- 「目隠しモード」で輪・拍番号を隠し、解除すると現在位置に戻る。
- 従来どおり、拍のタップ、裏拍切替、BPM変更、Save、再読込が使える。
- iPhone の縦画面で横スクロールが出ず、操作できる。

実施済み: production build、Chromium の390×844で上記表示・切替・再生を確認。
実機のSafariでのタップ操作と聴感は別途確認してください。

## 2. 合成音源とミキサー

- クララは2600Hzのバンドパス＋65msの複数アタック、ソルダは800Hzのローパス＋70ms。
- カホン低音は150→50Hzのサイン波を120msで減衰させ、弱いクリックを加える。
- スラップは45msのノイズ＋薄い320→260Hzの共鳴。
- ミキサーで各声部を1つずつ残し、音色の違いを聴く。強拍・通常拍・ゴーストの音量差を確認する。
- 再生中に音量／ミュートを変え、即座に反映されることを確認する。
- Save → ページ再読込で、音量とミュートが復元される。
- 元のMain/Offbeat Volumeは、それぞれ表拍／裏拍全体の音量として引き続き使える。

実施済み: OfflineAudioContextで4音色を実レンダリングし、非無音・減衰・
クララとソルダの帯域差・ベロシティによる音量差・全ミュート時の無音を検証。
Chromiumでミキサー保存と再読込を確認。サンプルファイル・追加ライブラリは使用していません。
